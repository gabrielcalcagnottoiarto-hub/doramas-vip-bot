# 💎 GRUPO VIP DA PELADA - VERSÃO ULTIMATE 💎

Esta versão é o resultado da fusão entre as versões **PRO v2** e **PRONTO PARA USAR**, totalmente otimizada para o **@GrupoVipdaPeladaBOT**.

## 🚀 O que esta versão tem?
- **Base Híbrida**: Combina a estabilidade da versão pronta com as funções avançadas da PRO v2.
- **Automação de Comandos**: O menu do Telegram (start, catálogo, vip) é configurado automaticamente.
- **Monetização Dupla**: Ganhe com assinaturas VIP ou com vendas de vídeos individuais.
- **Sistema de Anúncios**: Monetize usuários gratuitos exibindo propagandas no catálogo.
- **Broadcast**: Envie mensagens em massa para todos os seus usuários.

## 🛠️ Como Ligar
1. Abra o `main.py` e preencha o `TOKEN` e seu `ADMIN_ID`.
2. Instale as dependências: `pip install -r requirements.txt`
3. Execute: `python main.py`

## 👑 Comandos de Admin
- **Postar Conteúdo**: Envie um vídeo com a legenda: `/upload Titulo | Categoria | Preço | sim/nao`
- **Mudar PIX**: `/config pix sua_chave`
- **Adicionar Anúncio**: `/config ad texto do anuncio`
- **Dar VIP**: `/config vip id_usuario sim`
- **Mensagem Geral**: `/config broadcast sua mensagem aqui`
